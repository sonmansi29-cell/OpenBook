# 📚 OpenBook - Full Stack Bookstore

OpenBook is a modern full-stack bookstore web application built using React, Django REST Framework, PostgreSQL, and JWT Authentication.

## ✨ Features

- User Registration & Login
- JWT Authentication
- Book Catalog
- Collections
- Wishlist
- Shopping Cart
- User Profile
- Blog / Reading Journal
- Contact Page
- Responsive Design
- Protected Routes

## 🛠 Tech Stack

### Frontend
- React.js
- Vite
- React Router
- Context API
- Tailwind CSS

### Backend
- Django
- Django REST Framework
- JWT Authentication
- PostgreSQL
